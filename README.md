# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe** game built using **HTML, CSS, and JavaScript**.

The game includes **Light/Dark Mode**, a **game timer**, winner detection, draw detection, and restart functionality.


🚀 Features

* 🎮 Two-player gameplay
* ❌ Player X and ⭕ Player O
* 🏆 Automatic winner detection
* 🤝 Draw detection
* ⏱️ Game timer that runs until the game ends
* 🌞 Light Mode
* 🌙 Dark Mode
* 🔄 New Game option
* 📱 Responsive design
* ⚡ Built with pure HTML, CSS, and JavaScript
* 🚫 No external libraries or frameworks



 🛠️ Technologies Used

* **HTML5** – Creates the structure of the game
* **CSS3** – Handles styling, layout, responsiveness, and themes
* **JavaScript** – Implements game logic, timer, player interactions, and winner detection

 🎯 How to Play

1. Player **X** starts the game.
2. Players take turns clicking on an empty cell.
3. The first player to get **three symbols in a row** wins.
4. A winning combination can be:

   * Horizontal
   * Vertical
   * Diagonal
5. If all cells are filled without a winner, the game ends in a draw.
6. The timer runs while the game is in progress.
7. The timer stops automatically when a player wins or the game ends in a draw.
8. Click **New Game** to start a fresh game.
9. Use the theme toggle to switch between **Light Mode** and **Dark Mode**.



⏱️ Game Timer

The game includes a timer to track the duration of each match.

* Starts when the game begins
* Continues while the game is being played
* Stops automatically when the game finishes
* Stops when a player wins
* Stops when the game ends in a draw
* Resets when a new game starts

🌞🌙 Light & Dark Mode
The game supports two themes for a better user experience:

☀️ Light Mode
Provides a clean and bright interface.

🌙 Dark Mode
Provides a darker interface for comfortable gameplay in low-light environments.

Users can easily switch between the two themes using the theme toggle button.
